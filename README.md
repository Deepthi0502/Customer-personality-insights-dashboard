# Customer Personality Insights Dashboard

## Project Overview

An interactive Power BI dashboard for exploring customer demographics, income, and spending patterns.

## Tools Used

* Microsoft Power BI
* Data Visualization

## Key Features

* KPI cards displaying key metrics
* Income and customer spending analysis
* Customer comparisons by education and marital status
* Interactive slicers for exploring customer segments
